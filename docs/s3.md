# S3 archive output

The `s3` output writes each selected Adder event as one UTF-8 JSON object with
`Content-Type: application/json` and an S3 SHA-256 checksum. It uses the normal
AWS credential chain and the configured region. The bucket must already exist.

```yaml
output: s3
plugins:
  output:
    s3:
      region: us-east-1
      bucket: adder-archive
      prefix: adder/events
      event-types: blocks,transactions,rollbacks,governance
```

The key is `<prefix>/YYYY/MM/DD/<UTC timestamp>-<SHA-256 of JSON>.json`.
The JSON contains Adder's `timestamp`, `context`, `payload`, and `type` fields.
The date comes from the event timestamp in UTC. Replaying the same event writes
the same bytes to the same key. Different events with the same timestamp get
different keys. A rollback is an ordinary `input.rollback` archive record;
previously archived objects are not deleted or rewritten. Consumers must apply
rollback records when building chain state.

There is no batch buffer or background flush: the output waits for each
`PutObject` response before taking another event. The shared plugin input
channel can hold ten events; upstream sends then wait for space. Stopping
cancels an in-flight upload and discards queued events. AWS SDK retries are used for
retryable errors during that request, with a 30-second overall request limit.
An error is logged and reported through the plugin error channel when space is
available; sustained failures can fill its 16-entry buffer and later error
notifications may be dropped. Adder does not retain a
failed event for replay, and a timeout leaves delivery uncertain. Stop cancels
an in-flight request. For replay across process restarts, use a replayable
upstream source.

Required AWS permission: `s3:PutObject` on the selected prefix. If the bucket
uses customer-managed SSE-KMS, grant the needed KMS permissions as described by
AWS. See the current [PutObject API](https://docs.aws.amazon.com/AmazonS3/latest/API/API_PutObject.html)
and [AWS SDK for Go v2 S3 examples](https://docs.aws.amazon.com/sdk-for-go/v2/developer-guide/go_s3_code_examples.html).
